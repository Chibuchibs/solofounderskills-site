Install in 30 seconds

unzip solo-founder-skills.zip
mkdir -p ~/.claude/skills
cp -r skills/* ~/.claude/skills/

Claude picks them up next session and decides when to use each one. For a single project, use .claude/skills/ in that project instead. Full details in INSTALL.md inside the zip.

Where to start

If you're mid-build, read deploy-skew-guard and production-verification-loop. If you've built something and nobody's using it, start with channel-benchmarking and attribution-discipline — those two change what you do on Monday.

Make them yours

These get better when you add your own stack, your own numbers and your own market. And when Claude gets something wrong while following one, tell it to update the skill — it'll edit the file. That's how these were built in the first place.

Something broken or wrong? Reply to your receipt and I'll fix it — you'll get the update.
